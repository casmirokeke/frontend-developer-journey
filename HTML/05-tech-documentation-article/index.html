HTML Semantic Elements

A beginner-friendly guide to writing meaningful HTML.

Introduction

Semantic HTML means using HTML elements according to their meaning and purpose rather than using generic elements for everything.

Using semantic elements makes your website easier to understand, maintain, and navigate.

Why Use Semantic HTML?

Semantic HTML provides several benefits:

  • Improves accessibility
  • Creates better document structure
  • Helps search engines understand your content
  • Makes code easier to maintain

Common Semantic Elements

Some commonly used semantic elements include:

  • <header> - introductory content
  • <nav> - navigation links
  • <main> - primary page content
  • <article> - independent content
  • <section> - thematic grouping
  • <aside> - related or secondary content
  • <footer> - footer information

Example

A basic semantic HTML structure could look like this: 

<main>
  <article>

    <section>
      <h2>About HTML</h2>
      <p>HTML structures web content.</p>
    </section>

  </article>
</main>

Using Code in Documentation

Inline code can be written using the <code> element.

For example, the HTML heading element is written as: <h1>.

For multiple lines of code, combine <pre> and <code>.

Best Practices

  1. Use elements according to their meaning.
  2. Maintain a logical heading hierarchy.
  3. Use headings to organize sections.
  4. Keep code examples properly formatted.
  5. Write documentation that beginners can understand.

Quick Tip

Don't choose an HTML element simply because it looks the way you want. Choose it because it describes the content correctly.
